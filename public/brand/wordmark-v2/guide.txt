장소아카이브 이끼 · 워드마크 2.0

1. 기본 사용
horizontal: 심볼 왼쪽, 작은 장소아카이브와 큰 이끼를 두 줄로 배치합니다.
stacked: 심볼 위, 이끼와 장소아카이브를 아래에 중앙 정렬합니다.
compact: 심볼과 이끼만 사용합니다. 서비스가 이미 소개된 작은 헤더·워터마크에 적합합니다.

2. 파일 선택
*-teal.png: 밝은 바탕용, 투명 PNG.
*-white.png: 어두운 바탕·사진 위에 사용하는 흰색 투명 PNG.
*@2x.png: 같은 비율의 두 배 해상도 PNG. 영상 편집·SNS 작업에는 이 파일을 권장합니다.
*.svg: 글자는 윤곽선이며 심볼 PNG를 파일 안에 포함합니다. 폰트 설치와 외부 파일이 필요 없습니다.
SVG 전체가 순수 벡터는 아닙니다. 심볼은 원본 1254px 래스터이므로 무제한 확대나 대형 인쇄용 벡터 마스터로 취급하지 마세요.

3. 크기와 배치
가로형은 표시 너비 280px 이상, 세로형은 180px 이상을 권장합니다.
공간이 더 작으면 설명이 없는 compact를 선택하고 표시 너비 104px 이상을 유지하세요.
비율을 잠근 상태로 크기를 바꾸고, 파일 안의 투명 여백은 그대로 두세요.
사진 위에서는 밝기 대비가 충분하고 무늬가 적은 부분에 배치하세요.
쇼츠에서는 앱 버튼·자막 영역과 겹치지 않는지 실제 업로드 화면에서 확인하세요.

4. 글꼴과 원본
이끼: Pretendard SemiBold 600. 장소아카이브: Pretendard Medium 500.
공식 출처: https://github.com/orioncactus/pretendard
사용한 원본 커밋: 7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae
동봉된 원본 글꼴과 SIL Open Font License 문서를 함께 보관하세요.
심볼은 기존 이끼 마스터의 형태·색·점선·투명 여백을 유지합니다.
기존 앱 아이콘·사이트 헤더·쇼츠 영상은 이 파일들로 자동 교체되지 않습니다.
