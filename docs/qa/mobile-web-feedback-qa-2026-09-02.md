# 모바일 웹·피드백 미리보기 QA

**검수일:** 2026-09-02  
**대상:** `dev` Cloudflare Pages  
**결론:** 브라우저에서 재현 가능한 항목은 통과. 실제 iPhone·Android 앱 전환 항목은 실기기 확인 필요.

## 통과 항목

- 390×844 iPhone형 화면에서 메인 헤더, 검색, 사진 목록의 겹침과 가로 넘침이 없음을 확인했다.
- 360×800 Android형 화면에서 Explore Google 지도, 검색, 사진 목록 패널과 로그인 모달을 확인했다.
- Google OAuth 시작 뒤 기존 계정 세션으로 `dev` Explore에 복귀하고 사용자 사진 핀과 목록이 복원됐다.
- 마이페이지에서 `의견 보내기`가 `계정 관리`보다 위에 표시됐다.
- 피드백 모달의 유형, 1~5 만족도, 연락 동의, 1000자 입력과 내부 스크롤·하단 제출 버튼 접근을 확인했다.
- 피드백 제출 뒤 관리자 랜딩 편집 화면에 작성자, 유형, 만족도, 작성 화면, 연락 동의와 처리 상태가 표시됐다.
- 관리자 처리 상태를 `접수`에서 `검토 중`으로 변경하고 DB 반영을 확인했다.
- QA용 피드백 행은 확인 후 삭제했다.
- 공개 사진 2장은 위치 정보가 없어 익명 Explore에서 핀이 없는 현재 상태가 정상임을 DB 집계로 확인했다. 로그인 후 내 사진 12개의 위치 핀은 표시됐다.
- 모바일 헤더에서 로고·탐색·사진 추가·계정 버튼이 겹치던 문제와 이전 CSS 캐시 문제를 수정했다.

## 실기기에서 남은 확인

- iPhone Safari의 사진 보관함 선택, HEIC 변환 여부, EXIF 위치 읽기와 업로드 완료
- Android Chrome의 사진 선택기, 카메라 촬영 파일과 업로드 완료
- iPhone 노치·홈 인디케이터 및 Android 키보드가 열린 상태의 안전 영역
- KakaoTalk 앱 로그인 선택 뒤 Safari·Chrome으로 OAuth 콜백 복귀
- Kakao 공유 선택기와 KakaoTalk 앱 전환, 공유 카드·복귀
- 사진 상세 모달의 실제 터치 스크롤과 Street View 터치 동작

실기기 항목은 데스크톱의 반응형 크기 변경만으로 완료 처리하지 않는다.
