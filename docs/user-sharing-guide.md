# 이끼 이용자 안내와 공유 가이드

## 이용자에게 보낼 안내

이끼에 여러분의 여행 한 장면을 남겨보세요.

- **사진 한 장으로 장소를 나눠보세요.** 공개한 사진에서 공유 버튼을 누르면 사진 미리보기와 함께 카카오톡으로 보낼 수 있어요.
- **한 번의 여행을 하나의 앨범으로 만들어보세요.** 여행 사진을 골라 이름과 이야기를 붙이고, 함께 여행한 사람에게 앨범을 공유해보세요.
- **사진으로 나만의 지도를 채워보세요.** 촬영 위치가 있는 사진은 지도에 남아요. 위치가 없다면 기억나는 장소를 직접 지정할 수 있어요.
- **다음에 가고 싶은 장소를 모아보세요.** 마음에 드는 사진에 하트를 누르면 좋아요한 사진에서 다시 찾을 수 있어요.
- **아쉬운 점도 알려주세요.** 설정의 의견 보내기에서 불편한 점과 바라는 기능을 남겨주세요.

공유할 때는 사진과 앨범을 공개로 설정해주세요. 공개 앨범 안에서도 비공개 사진은 다른 사람에게 보이지 않아요. 집이나 다른 사람의 민감한 위치가 포함되어 있지 않은지도 확인해주세요.

## 안내용 이미지

카카오톡 안내에 함께 사용할 이미지 3장을 준비했습니다. 모두 1254 x 1254 PNG이며, 실제 화면 캡처가 아닌 기능을 설명하는 연출 이미지입니다.

- [사진 한 장 공유](announcements/assets/photo-share-kakao-v1.png): 사진 한 장으로 장소를 나눠보세요.
- [여행 앨범 공유](announcements/assets/album-share-kakao-v1.png): 사진과 장소가 담긴 앨범을 함께 나눠보세요.
- [여행 앨범 만들기](announcements/assets/trip-album-create-v1.png): 여행 사진을 골라 이름과 이야기를 붙여보세요.

이미지는 내장 이미지 생성 도구로 제작했으며, [제작 프롬프트](announcements/image-prompts.json)를 함께 보관합니다. 웹사이트에서 자동으로 불러오지 않는 안내 자료입니다.

## 사진 공유 방법

1. 공유할 사진의 상세 화면을 엽니다.
2. 더보기 옆의 공유 아이콘을 누릅니다.
3. 카카오톡을 선택하거나 링크를 복사해 보냅니다.
4. 받은 사람은 로그인하지 않아도 공개 사진을 열어볼 수 있습니다.

## 앨범 공유 방법

1. 내 사진에서 앨범 만들기를 엽니다.
2. 앨범 이름과 설명을 적고 사진을 고릅니다.
3. 공유할 사진 자체가 공개인지 확인한 뒤 앨범도 공개로 저장합니다.
4. 저장된 앨범의 공유 아이콘에서 카카오톡 또는 링크 복사를 선택합니다.

앨범 썸네일은 앨범에 포함된 공개 사진 중 첫 번째 사진을 사용합니다. 공개 사진이 없는 앨범은 사진 미리보기를 제공할 수 없습니다. 비공개 사진을 공유 때문에 자동으로 공개하지 않습니다.

## 알림 안내

- 내가 좋아요한 사진의 개수를 알림으로 반복 표시하지 않습니다. 모음 기능은 그대로 유지됩니다.
- 다른 사람이 내 사진에 남긴 새 좋아요만 모아 알려줍니다. 내 사진에 내가 누른 좋아요는 알림을 만들지 않습니다.
- 알림을 누르면 해당 시점까지의 좋아요 알림이 읽음 처리되어 사라집니다. 그 후 새 좋아요가 오면 다시 표시됩니다.
- 알림창을 열 때, 사이트로 돌아왔을 때, 사이트를 보고 있는 동안 최대 1분 간격으로 갱신됩니다.

## 운영 확인 사항

- 사진과 앨범 공유 주소는 각각 `/share/photo/사진ID`, `/share/album/앨범ID`입니다. 카카오톡 링크 미리보기를 위해 서버에서 Open Graph 정보를 제공합니다.
- 서버는 익명 권한과 명시적인 공개 필터로 사진 및 앨범을 확인합니다. 비공개 또는 삭제된 항목은 미리보기와 본문을 반환하지 않습니다.
- 공유 이미지에는 원본 대신 기존 미리보기 또는 썸네일 파일을 사용합니다. 별도의 유료 이미지 생성 서비스는 추가하지 않습니다.
- 사진을 비공개로 바꾸면 이끼의 공유 주소는 차단됩니다. 이미 전송되어 카카오톡에 캐시된 미리보기나 상대방이 저장한 사진까지 회수할 수는 없습니다.
- 카카오 JavaScript SDK 도메인과 Product Link 도메인에 실제 배포 주소가 등록되어 있어야 카카오톡 공유창이 열립니다. 열리지 않으면 링크 복사로 공유할 수 있습니다.

## 검증 기록

- 앨범 생성 성공과 사진 연결 실패 복구, 6장을 초과하는 같은 날 사진 표시, 비공개 사진 유지: 자동 테스트.
- 앨범 입력 내용의 사진 선택 왕복 유지, 모바일 공유창과 링크 복사·닫기: 브라우저 확인.
- 공개 사진 미리보기 이미지, 공개 앨범의 공개 사진 조회 관계: 실제 서버 응답 확인.
- 현재 서버에 공개 앨범이 없어 앨범 미리보기 구성은 테스트 데이터로 검증했습니다. 실사용자 로그인 상태의 앨범 저장과 실제 카카오톡 수신 화면은 별도 확인 대상입니다.
- 좋아요 생성·중복 요청·자기 좋아요 제외·읽음·새 좋아요 재알림·RLS: `test/received-like-inbox.sql`을 실제 DB에서 실행하고 전부 롤백했습니다.
- `mark_received_likes_read`의 SECURITY DEFINER 권한은 의도된 구조입니다. `auth.uid()` 본인 행만 변경하고 읽음 수는 받은 수 이하로 제한합니다. 익명 실행과 클라이언트 테이블 수정은 차단합니다. [Supabase 권한 점검 안내](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable)
- 성능 예산: 최신 원격 기준 JS Brotli 71.41 KiB에서 이번 변경 후 72.47 KiB로 약 1.06 KiB 증가했습니다. 기존 한도 70.5 KiB 초과는 여전히 남아 있으며 한도를 올려 통과 처리하지 않았습니다. CSS 29.97/30 KiB, 정적 이미지 2147.74/2200 KiB는 통과합니다. 신규 이미지나 클라이언트 패키지는 추가하지 않았습니다.
