# Ikkyee 첫 모바일 베타 배포 대상

**결정일:** 2026-08-30

## 결정

첫 배포는 iOS TestFlight 내부 테스트와 Google Play 내부 테스트로 진행한다. 두 플랫폼 모두 설치 가능한 서명 빌드를 소수 테스트 계정에 먼저 제공하며, 비공개 외부 베타와 공개 스토어 출시는 이 단계에 포함하지 않는다.

## 이유

- OAuth, 사진 권한, 딥링크, 지도 SDK처럼 시뮬레이터와 웹 export가 증명할 수 없는 동작을 스토어 서명 환경에서 먼저 확인할 수 있다.
- 공개 사용자와 운영 데이터에 영향을 주기 전에 설치, 업그레이드, 계정 삭제, 비공개 사진 경계를 검증할 수 있다.
- TestFlight와 Play 내부 테스트는 공개 출시보다 되돌리기와 테스트 대상 관리가 단순하다.

## 배포 순서

1. 운영과 분리된 preview 환경에서 EAS 내부 빌드와 핵심 smoke test를 통과한다.
2. 운영 자격 증명을 연결한 production 서명 빌드를 만든다.
3. TestFlight 내부 테스트와 Google Play 내부 테스트에 같은 앱 버전을 배포한다.
4. 설치, 업그레이드, 이메일·Google·Kakao 로그인, 사진 권한, Explore 지도, 공유 링크, 계정 삭제를 확인한다.
5. P0·P1 오류가 없고 개인정보·지원 문구가 승인된 뒤에만 외부 베타 또는 공개 출시를 별도로 승인한다.

## 제외 범위

- 첫 내부 테스트에서 공개 스토어 자동 배포를 하지 않는다.
- 실기기 검증 전 운영 DB 마이그레이션과 Edge Function을 앱 출시 완료로 간주하지 않는다.
- `expo-updates`가 없는 현재 상태에서 EAS channel을 OTA 배포나 롤백 수단으로 사용하지 않는다.
