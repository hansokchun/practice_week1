# 웹 개편 모바일 동기화 원장

기준일: 2026-09-05
웹 기준: 2026-09-05 `dev` 랜딩·메인·검색·태그 갤러리·로그인·사진 상세·지도 개편

## 확인한 웹 변경

- 웹은 전체 화면 사진 슬라이드 랜딩 뒤 관리형 공개 사진 메인으로 진입한다.
- 상단·고정 하단 탐색을 제거하고 로고, `사진 추가`, 로그인 또는 계정 메뉴만 둔다.
- 큰 공개 사진 검색, `도로·바다·사람` 추천 검색어, 관리형 가로 사진 섹션과 두 곳의 지도 진입을 제공한다.
- 웹의 태그 전체보기는 지도 없이 5열·30장 페이지와 지역 필터를 제공한다.
- 계정 메뉴는 `내 프로필`, `내 사진`, `좋아요한 사진`으로 제한한다.
- `내 사진` 안에서 사진과 웹 앨범을 전환한다.
- 사진 상세에서 주변 사진 목록을 제거하고, 정확 위치에서만 요청 후 거리뷰를 연다.
- 랜딩 제목은 `이끼에서 당신만의 장소를 찾아보세요`를 사용한다. 지도 진입은 큰 `지도에서 찾아보기` 버튼 하나로 정리하고, 하단 지도·핀 이미지는 문구나 카드 경계 없이 페이지 배경으로 페이드한다.
- 로그인 화면에서 소개·신규 계정 제한·개발자 안내 문구를 제거한다.
- 사진 상세는 하트만 있는 좋아요 버튼, `-- --` 날짜 대체, 스크롤 단서, 제목 높이의 메뉴, 소유자 전용 공개 상태, 작동하는 Explore 지도 이동을 사용한다.
- Explore의 `내 사진`은 공개 여부와 무관하게 소유자가 가진 위치 사진을 표시하고, `다른 사람 사진`은 공개 위치 정책을 유지한다.
- `app_metadata.role = admin`인 웹 운영자는 랜딩 섹션과 사진 순서를 관리한다.

## 운영 데이터 읽기 확인

2026-08-27 운영 publishable key의 익명 역할로 읽기만 수행했다.

- 공개 랜딩 섹션: 5개 (`추천`, `한국`, `일본`, `풍경`, `도시`)
- 관리자 사진 배정: 0개
- 랜딩 조회 가능한 공개 사진: 2개
- 공개 사진의 Storage 경로 형식: 모두 안전한 소유자 하위 경로

웹과 모바일은 `landing_section_photos`에 저장된 사진과 순서만 표시한다. 비어 있는 주제는 관리자 저장 시 좋아요한 공개 사진 중 주제에 맞는 후보를 한 번 무작위로 구성하고, 이후 같은 테이블 순서를 유지한다. 원본 사진 삭제 시 외래 키 연쇄 삭제로 해당 배정도 함께 제거된다.
