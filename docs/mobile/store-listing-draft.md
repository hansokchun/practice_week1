# Ikkyee 모바일 스토어 문구 초안

**상태:** 내부 테스트용 초안, 운영자 승인 전

## 앱 이름

Ikkyee

## 짧은 설명

사진 속 장소를 지도에서 다시 발견하는 여행 사진 기록

## 전체 설명

Ikkyee는 여행 사진과 장소, 위치를 함께 기억하는 사진 지도입니다.

기기 사진을 날짜와 위치로 정리하고, 원하는 사진만 직접 선택해 비공개로 보관하거나 다른 사람과 공유할 수 있습니다. Explore에서는 공개된 여행 사진을 지도와 장소 검색으로 둘러보고, 마음에 드는 사진을 좋아요로 모아볼 수 있습니다.

주요 기능

- 기기 사진을 원본 변경 없이 로컬에서 정리
- 위치가 있는 사진을 나만의 지도에서 확인
- 위치가 없는 사진에 직접 장소 지정
- 선택한 사진만 비공개 보관, 링크 공유 또는 공개 게시
- 공개 여행 사진의 지도 탐색, 장소 검색, 좋아요와 댓글
- Google, Kakao, 이메일 로그인과 계정 삭제

Ikkyee는 사진 보관함 전체를 자동으로 업로드하지 않습니다. 게시 전 선택과 확인을 거치며, 공개 위치 정밀도도 사용자가 결정합니다.

## 검색 키워드 초안

여행, 사진, 지도, 장소, 위치, 앨범, 여행기록, 사진정리, 추억, 제주

## 스크린샷 순서

1. 공개 사진 랜딩과 검색
2. Explore 지도와 사진 목록
3. 기기 사진 격자
4. 로컬 사진 지도와 위치 편집
5. 게시 전 공개 범위 확인
6. 사진 상세와 작성자 프로필

실제 스토어 등록 전에는 서명 release 실기기 화면으로 다시 촬영하고 계정, 알림, 좌표, 사진 속 개인정보를 제거한다.
