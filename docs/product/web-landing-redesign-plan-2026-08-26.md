## 1. 이번 개편의 목표

공개 여행 사진을 탐색하는 랜딩 페이지를 새로 만들고, 사진 추가와 개인 사진 관리를 더 쉽게 찾을 수 있도록 웹사이트 정보 구조를 단순화한다.

사용자가 랜딩 페이지에 들어왔을 때 다음 흐름을 자연스럽게 경험해야 한다.

```text
큰 검색창에서 여행지 탐색
→ 주제별 공개 사진 가로 목록 확인
→ 사진을 눌러 상세 정보·지도·거리뷰 확인
→ 오른쪽 위 사진 추가 버튼으로 본인 사진 등록
→ 계정 메뉴에서 프로필·내 사진·좋아요 사진 관리
```

## 2. 이번 개편에서 제외하는 범위

- AI 여행사진 정리 서비스
- 여행 전체·하루 단위 AI 분석
- AI 여행요약 생성 및 관련 화면
- 여행요약 계정 메뉴
- AI 분석 가격·무료 체험·구독 결제

AI 여행사진 정리는 나중에 별도 기획과 출시 관문을 거쳐 추가한다. 이번 랜딩 개편에는 버튼, 안내 문구, 빈 자리도 넣지 않는다.

- `사진 추가`를 누르면 별도의 사진 추가 페이지로 이동한다.
- 로그아웃 사용자가 누르면 로그인 후 원래 사진 추가 페이지로 돌아오게 한다.
- AI 정리 기능을 연상시키는 `여행 사진 정리하기` 문구는 사용하지 않는다.

## 5. 큰 검색창

검색창은 헤더 안의 작은 입력란이 아니라 랜딩 첫 화면의 중심 요소로 배치한다.

검색창 위 제목:

> 당신의 장소를 찾아보세요

검색창 플레이스홀더:

> 도시, 장소, 여행 분위기를 검색해 보세요

검색 대상:

- 국가와 도시
- 관광지와 장소
- 바다·강·산·호수 같은 자연 주제
- 계절과 여행 분위기
- 공개 사진 설명과 태그

검색창 아래에는 추천 검색어를 메시지형 칩으로 표시한다.

```text
제주 바다 · 서울 야경 · 부산 · 도쿄 골목 · 벚꽃 여행
```

실제 검색 통계가 없을 때는 `인기 검색어`라고 표시하지 않고 `추천 검색어` 또는 `지금 둘러보기`라고 표시한다.

검색창 위에는 제목 외의 아이브로우·소개 문장을 표시하지 않는다.

## 6. 관리자가 편집하는 랜딩 섹션

랜딩의 소제목과 그 안에 들어가는 사진은 관리자 화면에서 직접 구성한다.

관리 가능한 항목:

- 섹션 제목
- 선택 사항인 짧은 설명
- 섹션 공개·숨김
- 랜딩에서의 섹션 순서
- 섹션에 들어갈 공개 사진 선택
- 사진 표시 순서
- 섹션에서 사진 제거
- 한 번에 불러올 사진 수
- `모두 보기` 사용 여부와 연결 조건

예시:

```text
섹션 제목: 여름 바다
설명: 파도와 노을이 있는 여행 사진
선택된 사진: 28장
표시 방식: 직접 정렬
상태: 공개
```

관리 화면 권장 경로:

```text
/admin/landing
```

관리자 계정에서만 접근할 수 있어야 하며 일반 사용자의 계정 메뉴에는 표시하지 않는다.

## 7. 가로 사진 목록

- 첫 화면에는 섹션별 사진 일부만 표시한다.
- 데스크톱은 좌우 화살표, 트랙패드, 마우스 드래그를 지원한다.
- 모바일은 손가락 가로 스와이프를 지원한다.
- 다음 사진의 일부를 보여 가로로 더 볼 수 있다는 점을 알린다.
- 사용자가 끝에 가까워지면 다음 묶음을 추가로 불러온다.
- 이미 본 사진은 유지하고 새 사진을 기존 목록 뒤에 붙인다.
- 처음과 끝에서는 해당 방향 화살표를 비활성화한다.

권장 조회 단위:

```text
처음 8~12장
→ 끝에 가까워지면 다음 8~12장
→ 섹션의 마지막 사진까지 반복
```

같은 사용자의 사진이 한 줄을 지나치게 차지하거나 같은 사진이 여러 섹션에 반복되지 않도록 배치 경고를 제공한다.

## 8. 사진 상세 화면

공개 사진을 누르면 고유 주소가 있는 상세 화면 또는 전체 화면형 오버레이를 연다.

### 데스크톱

```text
왼쪽
├─ 큰 사진
├─ 관련 사진
└─ 아래로 스크롤한 뒤 Google Street View

오른쪽
├─ 작성자
├─ 장소·촬영일·설명
├─ 좋아요·공유
└─ 지도
```

- 왼쪽 사진 영역은 세로 스크롤할 수 있다.
- 오른쪽 정보와 지도는 가능한 범위에서 고정한다.
- Street View는 사용자가 `거리뷰 보기`를 눌렀을 때만 불러온다. 상세 열기만으로 `StreetViewPanorama` 객체를 생성하지 않는다.
- 주변 실외 파노라마는 `StreetViewPreference.NEAREST`로 가장 가까운 결과를 선택한다.
- 정확 위치 공개 사진에만 거리뷰를 연결한다.
- 근사 위치나 숨김 위치에는 원본 좌표 기반 거리뷰를 표시하지 않는다.
- Street View가 없으면 일반 지도와 주변 공개 사진을 보여준다.

### 모바일

```text
큰 사진
→ 작성자·장소·설명
→ 좋아요·공유
→ 지도
→ 거리뷰 보기
→ 관련 사진
```

## 9. 사진 추가 페이지

오른쪽 위 `사진 추가` 버튼을 누르면 별도 페이지로 이동한다.

권장 경로:

```text
/upload
```

기본 흐름:

```text
사진 선택
→ 파일 형식·크기 검증
→ EXIF 날짜·위치 확인
→ 사진별 설명·공개 범위·위치 정밀도 확인
→ 업로드
→ 내 사진으로 이동
```

- 새 사진은 기본 비공개로 등록한다.
- 사용자가 공개를 명시적으로 선택한 사진만 랜딩과 Explore 후보가 된다.
- 관리자 랜딩 섹션에는 공개 사진만 넣을 수 있다.

## 10. 계정 메뉴

계정 메뉴의 주요 개인 기능은 다음 세 가지로 단순화한다.

```text
내 프로필
내 사진
좋아요한 사진
```

하단 보조 기능:

```text
계정 설정
로그아웃
```

이번 구조에서는 계정 메뉴에서 다음 항목을 제거한다.

- 여행요약
- 별도의 앨범 메뉴
- 사진 추가

사진 추가는 랜딩 오른쪽 위의 독립 버튼으로 제공한다.

## 11. 내 프로필

`내 프로필`에서는 다음을 관리한다.

- 프로필 사진
- 표시 이름
- 소개
- 공개한 사진
- 공개 프로필 미리보기
- 프로필 편집

다른 사용자가 보는 공개 프로필과 본인 관리 화면을 구분하되, 본인은 공개 프로필에서 편집 모드로 들어갈 수 있다.

## 12. 내 사진

기존 My Photo 기능은 `내 사진` 화면으로 정리한다.

`내 사진` 안에서 다음을 볼 수 있다.

- 내가 올린 전체 사진
- 비공개 사진
- 공개 사진
- 위치가 없는 사진
- 사진별 상세·편집·삭제
- 내 앨범

앨범은 계정 메뉴의 별도 항목으로 두지 않고 `내 사진` 안의 탭 또는 섹션으로 제공한다.

권장 구조:

```text
내 사진
├─ 사진
└─ 앨범
```

필요하면 사진 탭 안에서 다음 필터를 제공한다.

```text
전체 · 비공개 · 공개 · 위치 확인 필요
```

## 13. 좋아요한 사진

`좋아요한 사진`은 계정 메뉴에서 바로 접근한다.

- 좋아요한 공개 사진 목록
- 가로·격자 보기
- 사진 상세 진입
- 좋아요 취소
- 원본이 비공개 또는 삭제된 경우 목록에서 안전하게 제거
- 목록이 비었을 때 랜딩 탐색으로 돌아가는 안내

```text
│  ├─ 사진
│  └─ 앨범
├─ /account/likes            좋아요한 사진
└─ /account/settings         계정 설정

관리자 영역
└─ /admin/landing            랜딩 섹션·사진 배치 관리
```

## 15. 구현 순서

### 1단계: 정보 구조와 화면 골격

- 상단 헤더를 로고, 사진 추가, 계정으로 단순화한다.
- 큰 검색창과 추천 검색어 영역을 만든다.
- 관리자 편집형 사진 섹션 자료 구조를 정의한다.
- 계정 메뉴를 내 프로필, 내 사진, 좋아요한 사진으로 바꾼다.

### 2단계: 랜딩 사진 탐색

- 소제목별 가로 사진 목록을 구현한다.
- 추가 묶음 조회와 가로 스크롤을 구현한다.
- 사진 상세 화면과 기존 지도 기능을 연결한다.
- Street View 지연 로딩과 미지원 상태를 추가한다.

### 3단계: 개인 화면 분해

- 기존 My Photo를 내 사진 화면으로 옮긴다.
- 앨범을 내 사진 안의 탭으로 옮긴다.
- 좋아요한 사진을 독립 화면으로 연결한다.
- 프로필과 계정 설정을 분리한다.

### 4단계: 관리자 랜딩 편집

- 섹션 생성·수정·숨김·순서 변경을 구현한다.
- 공개 사진 선택·제거·정렬을 구현한다.
- 권한 확인과 잘못된 비공개 사진 배치 방지를 구현한다.

### 5단계: 반응형·접근성·검증

- 데스크톱과 모바일 가로 스크롤을 검증한다.
- 키보드로 섹션과 사진을 탐색할 수 있게 한다.
- 검색, 사진 추가, 계정 메뉴, 상세, 관리자 흐름을 테스트한다.
- iOS Safari와 Android Chrome에서 스크롤·모달·지도를 확인한다.

## 16. 완료 기준

- 랜딩 첫 화면에 큰 검색창이 보인다.
- 검색창 위에는 `당신의 장소를 찾아보세요`만 보인다.
- 기본 소제목은 `추천`, `한국`, `일본`, `풍경`, `도시` 순서로 보인다.
- 사진 썸네일 위에 장소나 설명 글이 겹치지 않는다.
- 하단 `지도에서 확인하세요` 영역의 제목과 버튼이 겹치지 않는다.
- 상단에 별도 탐색 메뉴가 없고, 검색 아래와 사진 목록 끝에서 지도로 이동할 수 있다.
- 오른쪽 위에 독립된 `사진 추가` 버튼이 보인다.
- 사진 추가 버튼은 별도 사진 추가 페이지로 이동한다.
- 관리자가 랜딩 소제목과 사진을 직접 선택·정렬할 수 있다.
- 각 섹션은 가로 스크롤로 처음 보이지 않던 사진까지 탐색할 수 있다.
- 사진을 누르면 사진·정보·지도·거리뷰 상세를 볼 수 있다.
- 계정 메뉴의 핵심 항목은 내 프로필, 내 사진, 좋아요한 사진이다.
- 여행요약 항목이 표시되지 않는다.
- 앨범은 내 사진 안에서 볼 수 있다.
- AI 여행사진 정리 기능이나 문구가 이번 개편 화면에 나타나지 않는다.
