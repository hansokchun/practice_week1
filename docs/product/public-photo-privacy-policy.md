# 공개 사진 위치·시간·철회 정책

## 기본 원칙

- 새 사진은 `private`과 `approximate` 기본값으로 저장한다. 사진을 공개할 때는 `exact` 또는 `approximate` 위치 수준을 선택한다.
- 공개 전 사용자가 사진, 설명, 촬영일, 공개 위치 범위를 함께 검토한다.
- 공개 화면에는 촬영일만 표시하고 촬영 시각의 시·분·초는 공개 화면에 표시하지 않는다.
- 원본 좌표는 소유자 전용 저장소에 보관하며 공개 조회에 직접 제공하지 않는다.

## 위치 범위

- `exact`: 사용자가 명시적으로 선택한 경우 저장된 위치를 공개 지도에 표시한다.
- `approximate`: 공개 좌표를 소수점 둘째 자리로 반올림해 약 1km 범위만 표시한다.
- `hidden`: 이전 데이터와 비공개 호환을 위한 레거시 값이다. 사용자 화면에서는 선택할 수 없으며, 공개 사진에는 사용하지 않는다.

위치가 없는 사진은 `exact` 또는 `approximate`를 선택해도 지도 핀을 만들지 않는다. 공개 상태 변경은 원본 좌표를 삭제하거나 변경하지 않는다.

## 공개와 철회

- `public` 사진은 선택한 위치 범위에 따라 Explore와 공개 프로필에 표시한다.
- 이전 `hidden` 공개 사진은 마이그레이션 시 `approximate`로 정리한다. 현재 사용자 화면에서 공개 사진은 `exact` 또는 `approximate` 위치로만 저장한다.
- 사진을 다시 `private`으로 저장하면 Explore와 공개 프로필에서 즉시 제외한다.
- 공개 철회 후에도 사진, 설명, 촬영일, 원본 위치는 소유자의 Home에 유지한다.
- 다시 공개할 때는 현재 설명, 촬영일, 위치 범위를 다시 검토한다.

## 데이터 경계

- `photos.lat`, `photos.lng`: 공개 상태와 위치 범위가 허용한 공개용 좌표
- `photos.location_precision`: `exact`, `approximate`, `hidden` 중 하나
- `photo_private_locations`: RLS로 보호되는 소유자 전용 원본 좌표
- 데이터베이스 트리거가 공개 좌표 변환을 강제하므로 프런트엔드 요청으로 정책을 우회할 수 없다.
