# 공개 사진 위치·시간·철회 정책

## 기본 원칙

- 새 사진은 `private`으로 저장한다. EXIF 좌표는 `exact`, 지도에서 수동 지정한 좌표는 `approximate`를 기본값으로 사용한다.
- 공개 전 사용자가 사진, 설명, 촬영일, 저장한 위치와 위치 정확도 표시를 함께 검토한다.
- 공개 화면에는 촬영일만 표시하고 촬영 시각의 시·분·초는 공개 화면에 표시하지 않는다.
- 비공개 사진은 소유자만 조회할 수 있고 공개 사진은 저장한 좌표를 공개 조회에 제공한다.

## 위치 정확도

- `exact`: 사용자가 사진을 찍은 지점과 저장한 핀이 정확하다고 판단한 상태다.
- `approximate`: 사용자가 저장한 핀이 사진을 찍은 주변이지만 정확한 지점인지는 확신하기 어려운 상태다.
- 두 값은 위치에 대한 작성자의 판단을 설명한다. 좌표를 반올림하거나 이동시키지 않는다.

위치가 없는 사진은 위치 정확도와 무관하게 지도 핀을 만들지 않는다. 공개 상태 변경은 저장한 좌표나 위치 정확도를 변경하지 않는다.

## 공개와 철회

- `public` 사진은 위치가 있으면 같은 좌표로 Explore와 공개 프로필에 표시한다.
- 이전 `hidden` 값은 마이그레이션 시 `exact` 또는 `approximate`로 정리한다.
- 사진을 다시 `private`으로 저장하면 Explore와 공개 프로필에서 즉시 제외한다.
- 공개 철회 후에도 사진, 설명, 촬영일, 원본 위치는 소유자의 Home에 유지한다.
- 다시 공개할 때는 현재 설명, 촬영일, 저장 위치와 정확도 표시를 다시 검토한다.

## 데이터 경계

- `photos.lat`, `photos.lng`: 사용자가 저장한 지도 좌표
- `photos.location_precision`: `exact` 또는 `approximate`인 사용자 판단
- `photo_private_locations`: 이전 정책 호환과 좌표 복구를 위해 같은 좌표를 보관하는 소유자 전용 테이블
- 데이터베이스 트리거는 좌표 복구 사본만 동기화하며 공개 좌표를 변환하지 않는다.
