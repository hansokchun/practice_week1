# Ikkyee 앱 기능·화면 계획 - 간단 버전

## 제품 방향

- 앱의 주 기능은 `Explore`다.
- 사용자가 다른 사람의 공개 여행 사진을 지도와 사진 목록으로 탐색하는 경험을 가장 먼저 보여준다.
- 내 휴대폰 사진을 불러오고 위치를 확인하거나 공개하는 기능은 보조 기능으로 둔다.
- 여행 앨범 생성·편집·조회·공유 기능은 앱에 넣지 않는다.
- 이 변경은 모바일 앱에만 적용한다. 기존 웹의 앨범 기능과 데이터는 수정하거나 삭제하지 않는다.

## 앱의 기본 화면

### 1. Explore

- 앱 실행 후 가장 먼저 열리는 기본 탭이다.
- 지도 위에 공개 사진 핀을 표시한다.
- 지도를 움직이면 현재 영역의 사진을 자연스럽게 다시 불러온다.
- 사진 목록, 사진 상세, 작성자 프로필을 이어서 볼 수 있다.
- 좋아요, 댓글, 링크 공유, 사용자 신고·차단을 제공한다.
- `다른 사람 사진`과 `내 공개 사진` 범위를 전환할 수 있다.

### 2. 내 사진

- 휴대폰 사진을 날짜순 그리드로 보여준다.
- 촬영 위치가 있는 사진은 내 사진 지도에서 확인한다.
- 사진 원본, 촬영일, 위치 정보를 볼 수 있다.
- 위치가 없거나 잘못된 사진은 직접 위치를 지정하거나 수정한다.
- 선택한 사진만 비공개 클라우드 저장, 링크 공개, 전체 공개할 수 있다.
- 사진을 앨범으로 묶거나 정리하는 기능은 제공하지 않는다.

### 3. 좋아요

- 내가 좋아요한 공개 사진을 모아 본다.
- 사진을 누르면 Explore 사진 상세로 이동한다.
- 공개 범위가 바뀌거나 삭제된 사진은 안전하게 목록에서 정리한다.

### 4. 프로필

- 닉네임과 프로필 사진을 조회·수정한다.
- 내가 공개한 사진과 지도만 보여준다.
- 로그인 연결, 비밀번호 재설정, 로그아웃, 계정 삭제를 제공한다.
- 공개 앨범 탭이나 앨범 카드는 표시하지 않는다.

## 화면 모습

- 하단 메뉴는 `Explore · 내 사진 · 좋아요 · 프로필` 네 개로 구성한다.
- Explore는 지도가 화면의 중심이고, 사진 목록과 상세 정보는 지도 위 바텀시트로 연다.
- 사진을 먼저 보여주고 설명과 버튼은 작고 단정하게 배치한다.
- 웹의 딥그린과 크림색을 유지한다.
- 버튼과 패널은 8~10px 정도의 모서리로 통일하고 과한 그림자는 사용하지 않는다.
- 로딩 중에는 빈 지도나 갑작스러운 핀 이동 대신 지도 준비 후 핀과 목록을 자연스럽게 표시한다.

## 저장 방식

| 데이터 | 저장 위치 |
| --- | --- |
| 휴대폰 사진 원본 | 휴대폰 사진 앱 |
| 사진 썸네일 | 휴대폰 임시 캐시 |
| 사진 위치·촬영일·동기화 상태 | 휴대폰 SQLite |
| 사용자가 직접 저장하거나 공개한 사진 | Supabase |
| 계정, 닉네임, 좋아요, 댓글 | Supabase |
| 웹의 기존 앨범 데이터 | 기존 Supabase에 유지하되 앱에서는 사용하지 않음 |

## 핵심 동작

- 휴대폰 사진 원본은 자동으로 서버에 올리지 않는다.
- 앱을 다시 열면 새 사진과 삭제된 사진을 확인해 내 사진 목록과 지도를 갱신한다.
- 휴대폰에서 원본을 삭제해도 이미 공개한 서버 사진은 자동 삭제하지 않는다.
- 웹과 앱은 같은 계정, 프로필, 공개 사진, 좋아요, 댓글을 공유한다.
- 앱은 웹의 앨범 테이블을 읽거나 변경하지 않는다.

## 개발 순서

1. Explore 중심 화면 구조와 클릭 가능한 화면 시안을 먼저 확정한다.
2. iPhone·Android 사진 권한과 사진 읽기를 실제 기기에서 검증한다.
3. 웹과 같은 Supabase 로그인·프로필·공개 사진을 연결한다.
4. Explore 지도, 사진 목록·상세, 좋아요·댓글·공유를 구현하고 지도 성능을 실제 기기에서 검증한다.
5. 내 사진 그리드·지도·위치 수정·선택 공개를 구현한다.
6. 좋아요 목록, 신고·차단, 계정 삭제와 스토어 제출 조건을 마무리한다.

## 앱에서 제외

- 여행 앨범 생성, 편집, 삭제, 상세 화면
- 로컬 가상 앨범
- 웹에 저장된 앨범 조회와 관리
- 공개 앨범, 앨범 링크, 앨범 공유
- 휴대폰 기본 사진 앱의 시스템 앨범 수정
- 사용자 동의 없는 사진 원본 자동 업로드
- 첫 출시의 동영상과 RAW 지원

## 완료 기준

- 앱 실행 시 Explore가 기본으로 열리고 지도 탐색이 중심 경험으로 동작한다.
- 공개 사진 탐색, 상세, 좋아요, 댓글, 공유, 프로필 이동이 이어진다.
- 내 사진은 보조 탭에서 그리드·원본·지도·위치 수정·선택 공개가 가능하다.
- 앱 어디에도 앨범 생성·조회·편집·공유 UI가 없다.
- 기존 웹의 앨범 기능과 앨범 데이터는 이전과 동일하게 동작한다.
- iPhone과 Android 실제 기기 테스트를 통과한다.
